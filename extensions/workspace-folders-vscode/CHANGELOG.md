# Change Log

## [Unreleased]

### Added

- **Current Workspace** section: the workspace folders in order, ticked; drag to reorder them, untick and **Apply** to remove any of them (also ones no pin lists, marked *not pinned*, which can be **Pin**ned).
- **Rename in Workspace…** (<kbd>F2</kbd>): rename a workspace folder without renaming it on disk.

- The **Workspace Folders** view, split out of devc-vscode. Pin folders and Git repos (with their worktrees), tick the ones to open, and **Apply** to make them the workspace folders, with Source Control following. Commands are `workspaceFolders.*`; pins are stored by this extension, so ones made in devc-vscode start over.
